# Farmer Marketplace

A full-stack web application that connects farmers directly with consumers. Farmers can sell products directly while consumers can browse, purchase, and track their orders.

---

## Features

- Farmer Registration
- Consumer Registration
- Login & Authentication
- Product Management
- Shopping Cart
- Order Management
- Admin Dashboard
